# Mentoring Program

This repository contains tasks and exercises completed as part of a mentoring program designed to prepare me for a career in Data Science.

## 📚 Purpose of this repository

The main goal of this repository is to practice and reinforce knowledge gained during the mentoring program. It includes hands-on tasks based on completed learning materials, focusing on real-world Data Science skills.

## 🧠 Topics covered

The exercises in this repository may include, but are not limited to:

- Data analysis and data cleaning
- Statistics and probability
- Python programming for Data Science
- Data visualization
- Working with datasets (CSV, Excel, APIs)
- Basic machine learning concepts

## 🚀 Goal

To build practical skills and prepare for a Data Scientist role by solving real analytical problems and working with data.

## 📝 Notes

This repository is continuously updated as I progress through the mentoring program.
